# Corporação Torres
A empresa tem como objetivo ajudar as pessoas que têm muitas dificudades da parte fisica e mental com vários medicos e profissionais de educação fisica para ajudar os pacientes e clientes.

# Sobre a Corporação Torres 
É uma empresa multifuncional criado e pensado pelo fundador Guilherme Torres , no momento esta em fase de base .
